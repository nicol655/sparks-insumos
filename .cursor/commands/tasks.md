# Break a feature into tasks

Turn the approved `plan.md` into an executable checklist.

1. Read the feature's `spec.md` and `plan.md`.
2. Write `tasks.md` in the same folder from the TEMPLATE: ordered, independently
   testable tasks grouped into phases (Setup → Foundational → per user story by
   priority → Polish). Mark `[P]` for tasks that can run in parallel.
3. Give each task a clear file path and, where relevant, a test-first pairing.
4. Include a Dependencies section and a Definition of Done that requires `/verify`
   to pass and `.ai/progress.md` to be updated.

End by presenting the task list; then proceed with `/implement`.
